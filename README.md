# App Insights (Google Play Store App) Analysis – Tableau

## Project Overview

**App Insights is a Data Analytics Project** based on Google Play Store application data.

The project aims to uncover meaningful patterns and trends from application information such as **ratings, reviews, installs, app size, price, categories, genres, content ratings, and update activity**.

The analysis focuses on identifying factors associated with application success, understanding user preferences, and generating data-driven insights that can support business and product decisions.

This project was completed using **Tableau** for data analysis, visualization, and dashboard development.

---

# Business Problem

The Google Play Store contains applications across numerous categories and genres, with significant differences in their ratings, reviews, installations, pricing, and other characteristics.

The purpose of this analysis is to investigate these characteristics and identify patterns that may help stakeholders better understand application performance.

The project addresses questions related to:

* Application ratings
* Application installations
* User reviews
* Application categories
* Genres
* Application size
* Pricing
* Content ratings
* Application updates
* Free vs paid applications

The business problem and project objectives are based on the provided assignment document.

---


# Project Objectives

The primary objectives are:

1. Identify factors contributing to application success.
2. Understand how these factors can be leveraged.
3. Identify user preferences and behaviors.
4. Analyze relationships between ratings, reviews, installs, size, and price.
5. Identify high-performing categories and genres.
6. Analyze application update patterns.

# Data Preparation

The data was prepared before visualization and analysis.

The required preparation included:

* Handling missing values
* Converting data types
* Converting **Installs** to numeric values
* Converting **Price** to numeric values
* Removing duplicate records
* Standardizing text fields
* Formatting **Last Updated** as a date field

These requirements are specified in the assignment document.

The prepared dataset was then used in Tableau to create worksheets, charts, calculated fields, filters, and dashboards.
